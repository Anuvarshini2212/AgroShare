# AgroShare 🌱

## 📌 Overview
AgroShare is a full-stack MERN application designed to bridge the gap between farmers who own agricultural equipment and those who need it. The platform also integrates transport helpers, enabling seamless equipment delivery and logistics support.

The system is built with a role-based architecture, ensuring different functionalities for farmers, transport helpers, and administrators.

---

## 👥 User Roles & Functionality

### 🚜 Equipment Owner (Farmer)
- List agricultural equipment for rent
- Manage availability and pricing
- View rental requests

### 🌾 Equipment Renter (Farmer)
- Browse available equipment
- Rent equipment based on need
- Make secure payments

### 🚚 Transport Helper
- Register with personal and vehicle details
- Offer transportation services
- Get hired by farmers for equipment delivery

### 🛠 Admin
- Dashboard with analytics and charts
- Manage users and equipment listings
- Monitor transactions and system activity

## 🚀 Key Features
- 🔐 Role-based authentication & authorization
- 📦 Equipment listing and rental system

## 🛠 Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Payment Gateway: Razorpay

---

## 🔐 Security
- Sensitive data stored using environment variables
- Secure authentication flow
- Protected API routes based on user roles

---

## ⚙️ Installation

1. Clone the repository:
   git clone https://github.com/yourusername/AgroShare.git

2. Install dependencies:
   npm install

3. Create a `.env` file and add:
   RAZORPAY_KEY_ID=your_key
   RAZORPAY_KEY_SECRET=your_secret

4. Run the application:
   npm start
